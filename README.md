# Displacement dataset

Data to estimate disaster displacement, built from several public sources. The work starts from earthquakes, and the structure can be extended to floods and cyclones.

Every value says at which level it sits, which source it comes from, which period it refers to and, when known, when it became available.

## How the data flow

```
sources/  ──download──>  output/  ──build──>  dataset/  ──describes──>  dataset_variables.xlsx
```

1. **Download:** the scripts in `sources/` save raw data in `output/`. The steps are in `workflow.ipynb`.
2. **Extract:** `python -m sources.dataset.build` reads `output/`, with no network, and writes `dataset/`.
3. **Use:** open the tables in `dataset/<ISO3>/<YEAR>/`, or read them with `sources/dataset/access.py`.

## Folders

### `sources/`

| Folder | Content |
|---|---|
| `gdacs/` | Events, episodes, areas, impact runs, ShakeMap versions, plus EM-DAT and EMM through GDACS |
| `idmc/` | IDU (provisional) and GIDD (validated) displacement figures |
| `iom/` | IOM DTM stocks of IDPs |
| `hdx/` | HDX HAPI: needs, IDPs, refugees, returnees, food prices, food security, poverty |
| `inform/` | INFORM Risk indicators; the list is in `catalogs/` |
| `ghsl/` | Population and settlement class, by area (`ghsl.py`) and by admin unit (`admin.py`) |
| `boundaries/` | Administrative boundaries, saved once per country |
| `reliefweb/` | Reports, PDF text and embeddings |
| `montandon/` | Montandon STAC API: same event in other sources, hazards, aftershocks, impacts. Used as a comparison |
| `sentinel2/` | Sentinel-2 images; download code ready, not used yet |
| `utils/` | Shared helpers: folders (`paths.py`), files, geometry, SMOD classes |
| `dataset/` | The extraction scripts, see below |

### `sources/dataset/`

| File | Content |
|---|---|
| `registry.py` | The list of variables: original field, harmonised name, unit, level, validity. Edit it to add or rename a variable |
| `schema.py` | Standard columns and checks of the long tables |
| `gdacs.py`, `idmc.py`, `iom.py`, `hdx.py`, `inform.py`, `ghsl.py`, `reliefweb.py`, `montandon.py` | One extractor per source |
| `wide.py` | Tables by country and year; `RULES` says which variables become columns |
| `build.py` | Runs everything |
| `access.py` | Functions to read the dataset |
| `catalog.py`, `catalog_text.py` | The Excel file |

### `output/` (raw data)

```
output/<ISO3>/boundaries/              admin0.gpkg, admin1.gpkg, admin2.gpkg
output/<ISO3>/<YEAR>/country/          country data: hdx/, iom/, idmc/, ghsl/, inform_*
output/<ISO3>/<YEAR>/<TYPE>_<ID>/      one folder per event
    gdacs/                             event, card, EM-DAT, news, shakemaps/<SHAKEID>/
    reliefweb/                         reports and texts
    montandon/                         events, hazards, impacts
    episodes/<EPISODE>/                episode, impacts/, areas/<LABEL>/<RES>m/
output/_cache/idmc/                    world IDU dump
```

### `dataset/` (harmonised data)

```
dataset/<ISO3>/<YEAR>/
    admin0, admin1, admin2             one row per unit, one column per variable
    event, episode, location           one row per event, episode, location
    columns.csv                        source, unit and validity of every column
    grid/100m, grid/1000m              cells of each event and episode
dataset/_long/                         every value with all its detail, one row per value
```

Tables are in `.csv` and `.parquet`. Admin tables hold the last value valid at 31 December of the year, so they can include values from after an event. For pre-event values and nowcasts use `access.as_of` on the long tables.

`dataset_variables.xlsx` lists every variable by level and resolution, with sources, validity rules, coverage and known problems. It is generated by `build`: do not edit it by hand, and keep it closed while `build` runs.

## Levels

- **Geographic:** admin 0 (country), admin 1, admin 2.
- **Events:** event, episode, location, grid (several resolutions).

## Commands

```bash
python -m sources.boundaries AFG IDN              # boundaries, once per country
python -m sources.ghsl.admin AFG 2025             # GHSL numbers for admin 0, 1, 2
python -m sources.montandon AFG 2025              # Montandon for every event folder
python -m sources.dataset.build                   # everything in dataset/
python -m sources.dataset.build --sources hdx --iso3 AFG --no-grid
python -m sources.dataset.catalog                 # only the Excel file
```

```python
from sources.dataset import access

access.table("AFG", 2025, "admin2")               # the table of a country and year
access.columns("AFG", 2025, "admin2")             # validity of its columns
access.as_of("idp_stock", level="admin2", iso3="AFG", date="2025-08-31", strict=True)
access.links("EQ_1498339")                        # records of the other sources
```

## Keys

Put them in a `.env` file in the project folder. GDACS, INFORM, ReliefWeb and the boundaries need no key.

```
IDMC_CLIENT_ID=...
DTMAPI_SUBSCRIPTION_KEY=...
HDX_APP_NAME=...
HDX_APP_EMAIL=...
MONTANDON_API_TOKEN=...
```

The GHSL rasters are read from `RELEASE_ROOT` in `sources/ghsl/ghsl.py`.
